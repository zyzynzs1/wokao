# 本地启动与更新说明

## 当前这台电脑怎么启动

双击桌面上的 **「公考」快捷方式**。

- 实际程序：`C:\wokao-app\wokao.exe`
- 快捷键/窗口/任务栏图标已经换成 wokao 自己的图标（`C:\wokao-app\wokao.ico`）；
- 数据目录仍是 `%APPDATA%\wokao\data`，记录和会话不变。

> 这台电脑的 Windows 安全策略会终止未签名的 Electron exe，所以本机安装副本使用了
> Trae CN 的已签名 Electron 运行时（应用代码、数据、图标仍然是 wokao 的）。
> 因此 `C:\wokao-app\wokao.exe` 这个文件的发行者是 Trae CN，但桌面快捷方式和窗口图标是 wokao。

## 换电脑 / 以后使用原生 wokao.exe

已经生成原生便携版：

```
C:\wokao-portable\
桌面\wokao-portable.zip
```

- `wokao.exe` 使用 Electron 45 和 wokao 自己的图标，不再依赖 Trae；
- 把整个文件夹/zip 复制到另一台电脑，双击 `wokao.exe`；
- 未签名，所以新电脑首次可能提示未知发布者，点“更多信息 → 仍要运行”即可；
- 数据在新电脑的 `%APPDATA%\wokao\data`，换机时可把旧电脑的 `%APPDATA%\wokao` 整个复制过去。

当前这台电脑由于系统安全策略，原生未签名 exe 仍然会被终止，所以本机先用桌面快捷方式；
便携版用于其他电脑。

## 更新代码

```bash
npm run update
```

会更新：

- 项目根目录 `resources/app.asar`；
- 本机安装副本 `C:\wokao-app\resources\app.asar`。

如果要重新生成便携版：

```bash
npm run build
npx electron-builder --dir --publish never
# 然后把 dist-app\win-unpacked 复制成 C:\wokao-portable
```
