# 本地启动与更新说明

## 当前运行方式

应用安装在 **ASCII 路径** 下：

```
C:\wokao-app\wokao.exe
```

桌面上的 **「公考」快捷方式** 指向它，双击快捷方式即可启动。

数据目录仍是原来的：

```
%APPDATA%\wokao\data
```

所以历史记录、继续练习会话、设置都不会变。

## 为什么要安装到 C:\wokao-app

Windows 重启后开始拦截本项目里未签名的 Electron exe：

- 进程能创建，但会立刻以 `0x80000003` 退出；
- 关闭 Defender、关闭联想电脑管家防护、加信任区都试过，仍然拦截；
- 但 **Trae CN 自带的 Electron 运行时（有有效数字签名）能正常启动**。

因此当前版本使用 Trae CN 的已签名 Electron 运行时 + 本项目自己的 `resources/app.asar`。  
这样做只是为了让 Windows 允许 Electron 启动，应用代码、数据和功能都是本项目的。

另外，项目目录 `...\公考` 含中文，这个运行时在中文路径下会启动失败，所以必须放在 `C:\wokao-app`。

## 更新代码

```bash
npm run update
```

它会：

1. 构建 `out/`；
2. 更新项目根目录的 `resources/app.asar`；
3. 如果存在 `C:\wokao-app\resources\app.asar`，同步更新安装副本。

更新前请先关闭正在运行的「公考」。

## 注意

- 根目录旧的 `wokao.exe` 不能直接双击使用（中文路径 + Windows 拦截），请用桌面快捷方式。
- 如果快捷方式提示“未知发布者”，发布者应显示 Trae CN 的签名；这是运行时来源，不是应用本身。
- 以后若要彻底恢复原生 Electron 构建，需要给 exe 做可信代码签名，或者关闭 Windows 的 Smart App Control / 卸载拦截 Electron 的安全软件。
