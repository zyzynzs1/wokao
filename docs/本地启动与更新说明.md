# 本地启动与更新说明（避免 SmartScreen）

## 为什么会出现 SmartScreen

`wokao.exe` 是本地构建的、没有代码签名证书的 Electron 程序。Windows SmartScreen 按**文件哈希**判断“是否见过这个程序”：

- 每次 `npm run dist` 重新打包，都会生成一个**新的 wokao.exe 哈希**；
- 新哈希在本机没有运行记录 → 被当作“无法识别的应用”拦截；
- 之前没遇到过，是因为当时那个 exe 已经被允许过、或者一直没重新生成 exe。

这和应用本身有没有病毒无关。

## 当前采用的方案（不替换 exe）

根目录的 `wokao.exe` 已恢复为 **2026-10-16 那个本机已经运行过的版本**（SHA256 前缀 `427780C650CC1E55`），所以双击它不会再触发新的 SmartScreen。

最新代码放在：

```
resources/app/
  package.json
  out/
```

这个旧 exe 的 Electron fuses 是：

- `EnableEmbeddedAsarIntegrityValidation = Disabled`
- `OnlyLoadAppFromAsar = Disabled`

因此它会直接加载 `resources/app`，不需要 `app.asar`。

## 以后更新代码

不要再用 `npm run dist`（会重新生成 exe，又触发 SmartScreen）。

用：

```bash
npm run update
```

它会：

1. 构建主进程 / 预加载 / 渲染进程到 `out/`；
2. 把 `out/` 复制到 `resources/app/out/`；
3. **不改动 wokao.exe**。

更新前请先退出正在运行的 wokao。

## 备份

`backup-smartscreen-2026-10-27/` 里有：

- `wokao-current.exe`：本次重新打包的新 exe（已被 SmartScreen 拦截，通常不用）
- `wokao-old-1.exe`：当前使用的旧 exe 副本（SHA256 前缀 `427780C650CC1E55`）
- `wokao-old-2.exe`：另一个旧版本 exe 副本（SHA256 前缀 `FC50F83C2F300D55`）
- `app-current.asar`：重新打包时的 app.asar 备份

如果以后旧 exe 也出问题，可以先用备份里的另一个旧 exe 替换根目录的 `wokao.exe`（仍保持 `resources/app` 不动）。
