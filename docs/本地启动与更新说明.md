# 本地启动与更新说明（避免 SmartScreen）

## 为什么会出现“无法验证发布者”

`wokao.exe` 是本地构建的 Electron 程序，默认没有数字签名。Windows 对没有有效签名的 exe 会弹“打开文件 - 安全警告 / 未知发布者”，每次重新打包都会生成新的 exe 哈希，所以拦截会反复出现。

这和代码/病毒无关。

## 当前状态

根目录的 `wokao.exe` 已经用本机的开发证书签名，并且证书已加入当前用户信任：

- 证书主题：`CN=Wokao Local Dev, O=Wokao, C=CN`
- 证书指纹：`93E596418092146B4C3FF258CAC9F3AA75B5F0C6`
- 签名状态：**Valid（已通过验证）**
- 当前 exe SHA256 前缀：`16560E7F2478CF2F`

签名后的 exe 不会再把“未知发布者”作为拦截理由。证书只放在当前用户证书存储（CurrentUser\Root、CurrentUser\TrustedPublisher），不影响其他用户。

## 更新代码

不要再用 `npm run dist`（会重新生成 exe）。用：

```bash
npm run update
```

它会：

1. 构建 `out/`；
2. 把 `out/` + `package.json` 打成 `resources/app.asar`；
3. **完全不改动 wokao.exe**，因此不会重新触发 SmartScreen。

更新前请先退出正在运行的 wokao；如果 Trae/编辑器正打开着 `resources/app.asar`，可能会锁文件，需要先关闭对应编辑器窗口。

## 启动

直接双击根目录 `wokao.exe`。

如果 Windows 仍弹安全提示：

1. 确认提示里的“发布者”是不是 `Wokao Local Dev`；
2. 若是“未知发布者”，说明当前 exe 又被替换成了未签名版本，需要重新签名；
3. 若点击“运行”后没有窗口，把提示文字或现象告诉我，我再定位（下一版主进程会写 `%APPDATA%\wokao\startup.log` 启动日志）。

## 以后不想信任这个本地证书

可在 PowerShell 里删除：

```powershell
$thumb = '93E596418092146B4C3FF258CAC9F3AA75B5F0C6'
Remove-Item "Cert:\CurrentUser\Root\$thumb" -Force
Remove-Item "Cert:\CurrentUser\TrustedPublisher\$thumb" -Force
```

删除后 exe 会恢复为“未知发布者”状态，但仍可点击“运行”继续使用；如果希望永久不再提示，需要正规代码签名证书或关闭 SmartScreen 检查。
