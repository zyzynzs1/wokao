# 真题数据体检报告

日期：2026-10-27  
范围：内置 30 套真题（2016—2026 国考 27 套 + 辽宁 3 套）、168 道题

## 一、发现并已修复的问题

### 1. 大作文材料系统性拼接（27 套国考卷全部存在）

原来每套国考卷第 5 题（大作文/文章论述）的 `material` 字段被写成了**整卷材料拼接**（前面 4 题材料 + 第 5 则材料），所以打开第 5 题会先看到前面题的材料。

修复规则：

- 题干明确写“给定资料 N”的：只保留第 N 则材料；
- 题干同时引用多则材料的（如 2021 国考副省级引用资料 1、2）：保留被引用的几则；
- 题干没有指定具体材料的（“参考给定资料”）：保留全卷材料（这是合理的，因为题目要求参考全部资料）；
- 引用第 5 则/第 6 则但题目只给 4 题材料的：用“段落覆盖法”从原整卷材料里提取第 5/6 则。

已修复 **22 道**大作文材料，例如：

- `zt-gk-2026-ds-05`：7402 字 → **1014 字**（只保留“给定资料5”：环境考古/跨学科团队）
- `zt-gk-2026-05`：7153 → 1803 字（只保留资料2）
- `zt-gk-2026-zf-05`：6904 → 922 字（只保留资料5）
- 2025/2024/2023/2022/2019/2018/2017/2016 对应大作文均已按题干引用修正。

保留全卷材料的 5 道（题干未指定具体资料，属于合理设计）：
`zt-gk-2025-05`、`zt-gk-2025-ds-05`、`zt-gk-2023-05`、`zt-gk-2022-ds-05`、`zt-gk-2017-05`。

### 2. 题型标错（3 道）

这 3 道题干是公文写作，却被标成“文章论述”，现已改为“应用文写作”：

## 三、体检工具

- `npm run audit:exam`：检查套卷/题目/材料关联、题型与题干不匹配、材料过短、跨卷重复。
- `npm run fix:exam`：按题干引用自动修正大作文材料与明显标错的应用文题型（修改前请确认 git 状态）。
