## 3. 稳定性

同一份答案（gk-fs-zh-01）在**点池冻结**后连续三次评分：

```
旧双评版：12.5 / 14.5 / 13.0（最大差 2.0，满分 20）
三次多数票版：14 / 15 / 14（最大差 1.0，满分 20）
```

结论：三次独立判定 + 多数票 + 平均覆盖系数明显降低随机波动；但仍非完全确定，因此界面必须展示区间与置信度（已实现）。

## 4. 已知偏差与原因

1. **大作文偏严**：新引擎按袁东累进四类文 + 字数硬扣，两篇分别为 11/35、14/35；旧 app 20/22，Lead 独立复评 17/19。新引擎把“字数严重不足 + 标题未含主题词 + 论证空泛”按三类下处理，方向正确但当前偏严（Lead 复评可能偏宽）。需要下一轮用更多大作文样本校准（目标：让 658 字/922 字两篇的差距更合理，并让中心分贴近独立复评）。
2. **综合分析与部分应用文偏松**：gk-fs-zh-01 15/20、zt-gk-2026-ds-03 10/20 高于独立复评（10.5、5）。原因是三次多数票会把“部分覆盖”抬成“完整覆盖”，应用文板块级判定对格式缺失的惩罚偏轻。
3. **点池粒度问题**：gk-ds-2026-ds-04 建出 12 个要点（题面通常 4–6 个维度），导致该题 17/20 偏高。需要加“最多 6 个维度”的硬约束/重试。
4. **模型输出仍非完全确定**：同答案三次判定仍可能差 1 分左右；已通过区间/置信度提示，不能承诺单分数绝对不变。
5. **未完成**：参考答案重写（见下）、基准集回归（目前以 Lead 独立复评为银标准，样本 12 条偏少）。

## 5. 参考答案结论（回应用户问题）

**需要重新治理，但不建议整库推倒重写：**

1. **真题内置答案**：保留现有整理版并标注来源；只修正明显错误/过短的，避免引入新错误。
2. **自编练习题（21 道）**：全部重写。目标：字数达上限 85%–100%、内容落到材料具体信息、符合该文种格式。
3. **AI 自命题**：生成时参考答案纳入自检（字数/采分点/材料长度已实现部分校验）；参考答案与采分点不一致时拒绝重生成。
4. **结果页“参考范例”**：改为独立生成 + 质量校验（字数、题型格式、与内置答案相似度阈值），不再直接复用内置答案；标注“AI 示范，非唯一答案”。
5. 优先级：自编题 21 道 + 后续 AI 题；168 道真题不整体重写。
